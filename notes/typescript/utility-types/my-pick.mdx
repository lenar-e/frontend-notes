## Problem

Implement `MyPick<T, K>` — an equivalent of the built-in `Pick` — without using it.

```ts
interface Todo {
  title: string;
  description: string;
  completed: boolean;
}

type TodoPreview = MyPick<Todo, 'title' | 'completed'>;
// { title: string; completed: boolean }
```

## Explanation

- `K extends keyof T` — a generic constraint: only existing keys of `T` can be passed, otherwise it's a compile error.
- `[P in K]` — a mapped type: iterates over every member of the `K` union.
- `T[P]` — an indexed access type: takes the type of property `P` from `T`.
- The type is **homomorphic**: its keys come from `keyof T`, so the `readonly` and `?` modifiers carry over from the source type.

## Follow-up questions

<details>
<summary>How do you express Omit with MyPick?</summary>

```ts
type MyOmit<T, K extends keyof any> = MyPick<T, Exclude<keyof T, K>>;
```

`Exclude<keyof T, K>` keeps the keys of `T` that are not in `K`. Note that the built-in `Omit` doesn't restrict keys to `keyof T` — you can pass any key.
