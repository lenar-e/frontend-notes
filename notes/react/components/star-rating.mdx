## Условие

Сделайте компонент рейтинга из N звёзд:

- при наведении подсвечиваются звёзды до курсора;
- клик выбирает значение;
- есть режим «только для чтения»;
- компонентом можно пользоваться с клавиатуры и скринридера.

## Разбор

- **Контролируемый компонент:** значение хранит родитель (`value` + `onChange`), внутри — только временное состояние наведения `hovered`.
- **Семантика:** выбор одного значения из нескольких — это группа радиокнопок, поэтому `role="radiogroup"` и `role="radio"` с `aria-checked`. Скринридер прочитает «3 из 5, выбрано».
- **Roving tabindex:** `tabIndex={0}` только у выбранной звезды, у остальных `-1`. Tab заходит в группу одним шагом, а выбор меняется стрелками — так ведут себя нативные `<input type="radio">`.
- **Кнопки, а не `<span>`:** фокус, Enter и Space работают из коробки.

## Follow-up вопросы

<details>
<summary>Как сделать половинки звёзд?</summary>

Рисовать звезду двумя слоями: серый фон и жёлтую заливку с `width: 50%` и `overflow: hidden`. Значение при наведении считать по `event.nativeEvent.offsetX` относительно ширины звезды, шаг клавиатуры сделать 0.5.

</details>

<details>
<summary>Почему не нативные input type="radio"?</summary>

Можно и так — это даже надёжнее для доступности: визуально скрыть инпуты, а звёзды сделать `<label>`. Тогда стрелки и `name`-группа работают без JS. Кастомные кнопки дают больше контроля над поведением, но всю семантику приходится писать вручную.

</details>
