## Problem

Write a `useDebounce(value, delay)` hook that returns `value`, but updates it only after `delay` ms without changes. A typical use case is search: the request goes out not on every keystroke, but once the user stops typing.

## Explanation

- Every change of `value` re-runs the effect: the cleanup of the previous effect clears the old timer, and the new effect sets a fresh one.
- If `value` hasn't changed for `delay` ms, the timer fires and updates the state.
- `delay` is a dependency too: when it changes, the timer restarts with the new delay.

## Follow-up questions

<details>
<summary>How is useDebounce different from a debounced callback?</summary>

`useDebounce` delays a **value** — handy when an effect (a request) depends on it. A debounced callback (`useDebouncedCallback`) delays a **function call** — handy for event handlers. The callback version needs `useRef` so that the timer and the latest version of the function survive re-renders.

</details>
