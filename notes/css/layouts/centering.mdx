A classic question: "Center a block horizontally and vertically". A good answer names several ways and explains when each one fits.

## Flexbox

<HtmlPreview
  html={`<div class="parent">
  <div class="child">I'm centered</div>
</div>`}
  css={`.parent {
  display: flex;
  justify-content: center; /* along the main axis */
  align-items: center;     /* along the cross axis */
  height: 160px;
  background: #eef2ff;
}

.child {
  padding: 16px;
  background: #4f46e5;
  color: #fff;
}`}
/>

The most common option. Works for any number of children and doesn't require knowing the element's size.

## Grid

<HtmlPreview
  html={`<div class="parent">
  <div class="child">I'm centered</div>
</div>`}
  css={`.parent {
  display: grid;
  place-items: center; /* align-items + justify-items */
  height: 160px;
  background: #eef2ff;
}

.child {
  padding: 16px;
  background: #4f46e5;
  color: #fff;
}`}
/>

The shortest option — one property on the parent.

## position + transform

<HtmlPreview
  html={`<div class="parent">
  <div class="child">I'm centered</div>
</div>`}
  css={`.parent {
  position: relative;
  height: 160px;
  background: #eef2ff;
}

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%); /* shift by half of its own size */
  padding: 16px;
  background: #4f46e5;
  color: #fff;
}`}
/>

Good for overlays and modals: the element is taken out of the flow and doesn't affect its neighbors.

## When to use what

| Approach                     | When                                                      |
| ---------------------------- | --------------------------------------------------------- |
| `flex` + `justify`/`align`   | The default, especially with several children             |
| `grid` + `place-items`       | A single element, maximum brevity                         |
| `absolute` + `transform`     | The element must sit above the content (modal, tooltip)   |
| `margin: 0 auto`             | Horizontal only, for a block element with a set width     |
