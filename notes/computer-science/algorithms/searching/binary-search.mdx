## Problem

Given an array of numbers sorted in ascending order and a number `target`, return the index of `target` in the array, or `-1` if it's not there. The solution must run in O(log n).

```ts
binarySearch([1, 3, 5, 7, 9], 7); // 3
binarySearch([1, 3, 5, 7, 9], 4); // -1
```

## Explanation

- At every step, compare `target` with the middle element and discard the half where it can't be.
- The key is to keep the **invariant**: if the element exists, it always lies in `[left, right]`. Hence the `left <= right` condition and the `mid ± 1` moves.
- Common mistakes: `left < right` instead of `<=` (the last element is lost), `left = mid` instead of `mid + 1` (infinite loop).

| Time     | Space |
| -------- | ----- |
| O(log n) | O(1)  |

## Follow-up questions

<details>
<summary>How do you find the first occurrence when there are duplicates?</summary>

On a match, don't return right away — remember the index and keep searching in the left half: `result = mid; right = mid - 1`. For the last occurrence, do the opposite: `left = mid + 1`.

</details>
